Then put Mario64.zip into the Sonic 3 A.I.R. mods folder:

Android/data/org.eukaryot.sonic3air/files/mods

  1. Start Sonic 3 A.I.R. once, so the folder exists.
  2. Open a file manager that can access Android/data. On Android 11 and newer, the built-in one usually can't. Use one that can, like ZArchiver, or connect the phone to a PC.
  3. Copy or move Mario64.zip into that mods folder. Leave it zipped.

Put Mario64.zip into the mods folder of Sonic 3 A.I.R. (leave it zipped):

  • Windows: %APPDATA%\Sonic3AIR\mods
  • Linux: ~/.local/share/Sonic3AIR/mods
  • macOS: ~/Library/Application Support/Sonic3AIR/mods
  • Android: Android/data/org.eukaryot.sonic3air/files/mods

Then start the game, open Mods in the main menu and enable Mario 64 (SM64 movement) v2.2.5. Pick Mario in Data Select: he comes after Knuckles.

Installed an earlier version? Delete the old Mario64 folder from the mods folder, or deactivate the mod called just Mario 64. Otherwise the game keeps using the old Mario, who moves like Sonic.
